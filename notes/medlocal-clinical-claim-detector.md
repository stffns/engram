# v1c-6L repositioned as MedLocal ClinicalClaimDetector

Context: the session on 2026-04-20 trained `NanoGPTMidloopDecider`
through 7 rounds (v0 -> v1c-6L, VAL F1=0.461). After reviewing the
outcome with Jay we realised the model we trained is NOT the generic
midloop -- it is a **domain-specific claim-divergence detector for
clinical content**. This note formalises that reposition so the
artifact is not lost.

Honest caveat (2026-04-20, Jay): since the generic midloop grounds
responses via vstash retrieval, the knowledge inside v1c-6L's weights
is redundant with the text that already lives in the staged corpus
(WHO PDFs + HF guidelines). A pure retrieval-based MedLocal pipeline
could skip v1c-6L entirely by indexing the same protocols into
vstash and letting snapvec search at inference time. v1c-6L's real
niche is edge deployments where vstash + snapvec + embedder add too
much footprint and a single 11 MB tagger is preferable. For MedLocal
that tradeoff needs a measurement pass before investing more in
training this line.

See `notes/midloop-architecture-v2.md` for the generic midloop
architecture.

## What v1c-6L actually is

A 2.8M-param GPT-style per-position tagger (6L / 6H / 192d,
block_size 320, vocab 512) that, given:

- a CHW prompt describing a clinical scenario, and
- the first K tokens of a small-model response,

outputs a per-subword probability of "the next token starts a
divergence from what a WHO / ICRC protocol would say".

Trained on 3090 synthetic cases derived from:

- 77 MedLocal protocols (medlocal authoritative corpus)
- 440 HF epfl-llm/guidelines chunks (WHO + ICRC, density-filtered)
- 101 WHO-PDF sections (IMAI acute care, essential medicines, IMCI,
  snakebite, maternal-newborn, postnatal, adaptation)

Cases generated by Gemini 2.5 Flash structured output,
small-model responses by lmstudio gemma-4-e4b-it-mlx, divergence
labels by the merken aligner at cos=0.85 semantic drop filter.

Best VAL F1 = 0.461 at threshold 0.88 on a 62-protocol held-out
slice (10.1% of the 618 total protocols). train-val gap +0.157 --
some memorisation but not catastrophic.

## How it fits into the generic midloop

Plug-in point: `ClaimVerifier` for the clinical domain. When the
generic midloop triggers retrieval because `ClaimDetector` fires
on a step, and the top-K retrieved memory events are WHO / ICRC
protocols, the ClaimVerifier can be either:

- LLM-based (Gemini) -- works for any domain
- **v1c-6L** -- faster (1 ms/step on MPS), trained specifically
  on this domain's content

For MedLocal specifically (CHW in low-resource settings running
gemma-4-e4b-it-mlx offline), v1c-6L is the right verifier. Offline
operation, no API roundtrip, 11 MB RAM footprint.

## Graduation pathway for MedLocal

The "F1 >= 0.50 shadow bar" analysis from RESULTS_v1 still
applies -- just with the understanding that the shadow mode lives
inside MedLocal's pipeline, not the generic merken loop. Task #8
is now "ship v1c-6L as MedLocal's clinical-claim verifier, shadow-
mode, accumulate real (decision, outcome) pairs" rather than "add
a fifth merken decision primitive".

Integration points (MedLocal side, not engram):

1. `ClinicalClaimVerifier(ckpt=v1c-6L, meta=...)` wrapper module.
2. MedLocal runtime inserts the verifier at the same spot the
   midloop plan proposed: per-step during the small model's
   response generation.
3. Action clamped to WHISPER. If verifier confidence >= 0.88, the
   CHW sees a highlighted flag with the WHO reference paragraph.

## Optional: finish-training v1c-6L

The model plateaued at VAL F1 = 0.461 with the session's data
rounds. Two cheap levers NOT explored that might push F1 further
if we want to keep scaling the MedLocal artifact (not the generic
midloop):

1. **Multi-task auxiliary head**: protocol-id classification as
   secondary task. Adds inductive bias about protocol identity,
   might help transfer to unseen protocols. ~15 min to implement,
   1 hour to run.
2. **Corpus expansion to epfl-llm CDC + NICE** (2549 more docs).
   Cost: $4-6 Gemini, 3-4 hours wall time. Expected gain +0.005 to
   +0.015 based on the diminishing returns pattern.

Neither blocks the generic midloop work. Both produce a sharper
MedLocal artifact.
