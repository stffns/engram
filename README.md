# engram

> Agent-loop layer for persistent memory, built on top of [vstash](https://github.com/stffns/vstash).

**Status:** pre-code. Read [`CONSTITUTION.md`](CONSTITUTION.md) first — it defines what engram is, what it isn't, and what to do on day 1.

## In one paragraph

vstash is a glass-box retrieval substrate. engram is the loop on top: when to write a memory, when to recall, when to consolidate raw events into facts, when to forget. vstash is a hard dependency; engram never reimplements retrieval.
